# Review Alert playground

An open pull request for trying [Unsubmitted Review Alert for GitHub](https://github.com/nikita-dmitrienko/unsubmitted-review-alert),
a Chrome extension that warns you when you started a pull request review but never submitted it.

1. Install the extension.
2. Open the pull request in this repository and go to **Files changed**.
3. Click **+** next to any line, write a comment, click **Start a review**, and don't submit it.
4. A bar at the bottom of the page reminds you that your review is not submitted.

Pending review comments are visible only to their author until submitted, so trying it here bothers nobody.
The pull request stays open on purpose.
